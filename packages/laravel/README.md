# quittio/laravel

Laravel integration of Quittio: facade, configuration, Blade templates, Artisan commands and testing helpers.

```bash
composer require quittio/laravel
```

Most applications install everything at once with `composer require quittio/quittio` (core, Laravel integration and the country pack Germany).

- Documentation: https://quittio.github.io/quittio/
- Source, issues and pull requests: https://github.com/Quittio/quittio

> This repository is a read-only split of `packages/laravel` in [Quittio/quittio](https://github.com/Quittio/quittio). Please open issues and pull requests there.
