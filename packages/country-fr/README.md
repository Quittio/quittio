# quittio/country-fr

Country pack France for Quittio: the mentions of the CGI (from 2027 citing the CIBS) and the Code de commerce, the mentions of the e-invoicing reform, SIREN and SIRET, Factur-X for domestic business invoices, late payment penalties.

```bash
composer require quittio/country-fr
```

The pack is not part of `quittio/quittio`; install it next to `quittio/quittio` or `quittio/core`.

- Documentation: https://docs.quittio.dev/country-fr
- Source, issues and pull requests: https://github.com/Quittio/quittio
