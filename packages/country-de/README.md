# quittio/country-de

Country pack Germany for Quittio: UStG mandatory fields, tax presets, XRechnung profiles and BR-DE rules, tax number checks, default interest and DIN 5008 letter layouts.

```bash
composer require quittio/country-de
```

Most applications install everything at once with `composer require quittio/quittio` (core, Laravel integration and the country pack Germany).

- Documentation: https://quittio.github.io/quittio/
- Source, issues and pull requests: https://github.com/Quittio/quittio

> This repository is a read-only split of `packages/country-de` in [Quittio/quittio](https://github.com/Quittio/quittio). Please open issues and pull requests there.
