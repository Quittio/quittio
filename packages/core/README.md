# quittio/core

Country-neutral core of Quittio: EN 16931 data model, calculation, profiles, CII and UBL writers and readers, ZUGFeRD/Factur-X PDF/A-3 and validation. Usable without Laravel.

```bash
composer require quittio/core
```

Most applications install everything at once with `composer require quittio/quittio` (core, Laravel integration and the country pack Germany).

- Documentation: https://quittio.github.io/quittio/
- Source, issues and pull requests: https://github.com/Quittio/quittio

> This repository is a read-only split of `packages/core` in [Quittio/quittio](https://github.com/Quittio/quittio). Please open issues and pull requests there.
