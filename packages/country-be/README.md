# quittio/country-be

Country pack Belgium for Quittio: mandatory fields of the VAT Code and Royal Decree No. 1, tax presets, Peppol BIS for domestic business invoices with enterprise numbers, the language regions, default interest of the law of 2 August 2002.

```bash
composer require quittio/country-be
```

The pack is not part of `quittio/quittio`; install it next to `quittio/quittio` or `quittio/core`.

- Documentation: https://docs.quittio.dev/country-be
- Source, issues and pull requests: https://github.com/Quittio/quittio
