# Security policy

## Supported versions

Security fixes are released for the latest minor version (currently 0.8.x) of `quittio/quittio`, `quittio/core`, `quittio/laravel` and the country packs `quittio/country-de`, `-at`, `-be`, `-ch` and `-fr`.

## Reporting a vulnerability

Please do not open a public issue. Report vulnerabilities privately through GitHub: [Report a vulnerability](https://github.com/Quittio/quittio/security/advisories/new). Include the affected version, the steps to reproduce and, if possible, a sample invoice or input file with fictitious data.

## What happens next

Quittio is maintained by one person, so these are targets, not guarantees:

- You get an acknowledgement within 7 days.
- Within 14 days you get an assessment: whether the report is accepted, its severity and the planned fix.
- Accepted vulnerabilities are fixed in a patch release of the supported version. The advisory is published with the release, and you are credited unless you prefer not to be.

Please keep the report confidential until the fix is released.
